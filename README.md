# Apartment Lease App — 1 RK Rental Listing (Mumbai)

A clean, mobile-friendly landing page built for an owner-direct **1 RK flat rental in Mumbai** with zero brokerage. Designed to showcase flat highlights, an indicative floor layout, and let prospective tenants send structured inquiries directly via WhatsApp.

## ✨ Features

* **Direct-to-Owner Inquiry:** Eliminates middlemen with one-tap **WhatsApp** and **Call** actions.
* **Key Rental Highlights:** Displays monthly rent, security deposit, availability date, furnishing status, and area at a glance.
* **Indicative Floor Plan:** Visualizes the main room, kitchen, fridge, washer, bath/toilet, AC placement, and window orientation.
* **Pre-Formatted WhatsApp Lead Form:** Captures tenant name, profile (*Working professional*, *Student*, *Couple*, or *Family*), and target move-in date before opening WhatsApp.
* **Compliance Note:** Highlights standard Maharashtra rent agreement and police verification requirements.

## 🚀 Getting Started

1. **Clone or download** this repository:
   ```bash
   git clone https://github.com<your-username>/apartment_lease_app.git
   ```
2. **Customize your details** in `index.html`:
   * Fill in the monthly rent, deposit, availability date, furnishing status, and area.
   * Replace the placeholder phone number and WhatsApp link (`wa.me/91XXXXXXXXXX`) with your own.
   * Add actual photos of the flat in the gallery section.
3. **Preview locally** by opening `index.html` in any web browser.
